```text
# Queue format reference (version 1)

This file is generated by PlanMaster. Do not edit it.

## Files

- `.planmaster/lanes/<LANE>.md` is the live queue of one lane. Only that lane's chat writes to it.
- `.planmaster/archive/<LANE>.md` holds closed items moved out of the live file. Same format.
- `.planmaster/config.json` holds the list of valid people for `wait:` and some thresholds.

## Lane file

    ---
    format: 1
    lane: B
    title: Automated checks, gates and ratchets
    ---

    - [~] B-12 Survey existing checks since:2026-11-02T10:55
      - [x] B-12a List ratchets with frozen debt done:2026-11-02T11:02
      - [~] B-12b Measure the cost of each check since:2026-11-02T11:05
    - [ ] B-13 Add a signing-key check ref:R-198
    - [!] B-14 Make the fingerprint a ratchet wait:alice since:2026-11-01T17:30

## Line grammar

    <indent>- [<marker>] <ID> <title> <tokens>

- Indent: two spaces per level. Maximum four levels.
- Marker: space (todo), `~` (in progress), `!` (blocked), `x` (done), `-` (dropped).
- ID: `<LANE>-<number>` for top-level items (`B-12`), parent ID plus a suffix for children (`B-12a`, then `B-12a1`).
- Title: free text on one line, at most 120 characters.
- Tokens: at the end of the line, in this order, no spaces inside a value:
  - `ref:<value>`    link to a plan, ticket or document; several values separated by commas
  - `wait:<value>`  a person from config.json, or the ID of another item
  - `since:<time>`  when the item entered its current state
  - `done:<time>`   when the item was closed
- Time: `YYYY-MM-DDTHH:MM`, local time. Get it from `date +%Y-%m-%dT%H:%M`. Never guess it.

## Tokens required by state

    [ ]   no tokens (ref optional)
    [~]   since
    [!]   wait, since
    [x]   done
    [-]   done

## Changing state (edit the one line)

    todo -> in progress   set [~], add since
    in progress -> done   set [x], remove since, add done
    in progress -> blocked   set [!], add wait, replace since
    blocked -> in progress   set [~], remove wait, replace since
    any open -> dropped   set [-], remove wait and since, add done
    closed -> in progress (reopen)   set [~], remove done, add since

## Hard rules

- At most one top-level item is `[~]` per lane, and at most one `[~]` among the children of one parent.
- A parent may be closed only when all its children are closed.
- IDs are unique across all lanes and the archive, and are never reused.
- New top-level ID: highest number used in the lane's live file and its archive, plus one.
- Write only to your own lane file, one line per edit. Do not reformat, reorder or rewrite the file.
- Blank lines and single-line HTML comments are allowed. Nothing else besides items.
```
