What Claude is told

The extension never writes to the queue. It generates the instructions, keeps them up to date, and shows in the Problems panel when Claude does not follow them.

  • PlanMaster: Install Instructions in CLAUDE.mdWrites or updates the managed block between its two markers, after showing a diff. The rest of the file is untouched.
  • PlanMaster: Copy Lane Start PromptFor a new chat: tells it which lane is its own, where to write and where to resume.
  • PlanMaster: Copy Migration PromptExtracts open items from an existing to-do document into lanes. Keeps your IDs as ref:, leaves the prose alone.
  • PlanMaster: Copy Plan-to-Queue PromptAfter plan mode, turns the approved plan into queue items.
  • PlanMaster: Copy Reconcile PromptAsks Claude to compare a lane with files, tests and git, and to correct items that are wrong.
  • PlanMaster: Copy Archive PromptMoves closed subtrees older than N days to the archive.
